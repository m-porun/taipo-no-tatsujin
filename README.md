# webapp_skill

このリポジトリは、プログラミング未経験または初心者の社会人が、課外で初めての個人プロジェクトとして、ワークショップで `skill` を使いながら Web アプリ作りを進めるためのサンプルです。

## まず知っておくこと

この workshop では、最初から全部を自分で書くよりも、`skill` にやりたいことを伝えながら、シンプルな Web アプリを少しずつ完成させる使い方を想定しています。

`skill` は、作業の進め方を助けるためのガイドや補助機能です。  
まずは「何を作りたいか」「次に何をしたいか」を短く伝えるところから始めてください。

## はじめる手順

1. このリポジトリを自分のパソコンにコピーします。

   ```bash
   git clone https://github.com/RilaKorila/webapp_workshop.git
   cd webapp_workshop
   ```

2. 使いたいデスクトップ版の AI Agent で、このフォルダを開きます。

3. 次のメッセージをコピーして、AI Agent に送ります。Agent ごとの設定ファイルが必要な場合も、このメッセージを送れば Agent 自身が判断して準備します。

   ```text
   このリポジトリでワークショップを始める準備をしてください。

   まず、次の2つのファイルを読んでください。

   - AGENTS.md
   - .agents/skills/nextjs-workshop-sns/SKILL.md

   次に、あなたがこのリポジトリで自動的に読む設定ファイルがある場合は、その設定ファイルを追加または更新してください。

   設定ファイルには、次のことだけを書いてください。

   - AGENTS.md を共通ルールとして読むこと
   - .agents/skills/nextjs-workshop-sns/SKILL.md を、ワークショップでSNS風Webアプリを作るときの進め方として読むこと

   すでに設定ファイルがある場合は、内容を消したり大きく書き換えたりせず、必要な案内だけを追加してください。
   設定ファイルを使わない場合は、この会話の中では上の2つのファイルを読んでルールに従ってください。

   準備ができたら、変更したファイル名と、これから始める最初の1ステップを短く教えてください。
   ```

4. 準備ができたら、作りたいテーマを AI Agent に伝えます。例: 「読書記録のミニSNSを作りたい」

## skill の使い方

基本は、やりたいことを日本語でそのまま伝えれば大丈夫です。

例:

- 「プロフィール画面を追加したい」
- 「投稿一覧をカード風にしたい」
- 「このボタンをもっと目立つデザインにしたい」
- 「localStorage に保存できるようにしたい」
- 「今のコードを初心者向けに説明して」

必要なら、使いたい skill 名を一緒に書いても構いません。

例:

- 「`nextjs-workshop-sns` を使って、SNS らしい 投稿画面を作りたい」

## アプリ作りを進めるときのコツ

1. 作りたい画面や機能を 1 つだけ決める
2. その内容を短い日本語で伝える
3. 返ってきた内容を見て、足したい点や直したい点を続けて伝える
4. 一度にたくさん頼まず、小さく区切って進める

## コツ

- 「何をしたいか」が入っていれば十分です
- 困ったら「初心者向けに説明して」と付けると進めやすくなります
- 見た目を整えたいときは、画面名と雰囲気を一緒に伝えると伝わりやすいです

例:

- 「新規投稿ページを、やさしい雰囲気で見やすくしたい」
- 「読書記録のマイページを SNS っぽくしたい」

## 迷ったとき

何から始めればよいか分からないときは、まず次のように聞いてください。

- 「この workshop では次に何を作るのがおすすめ？」
- 「進めやすい順番で作業を分けて」
- 「今の状態から、次にやることを 3 つ出して」
